# Software Engineering Project

- This app requires flutter in order to run, so make sure it is downloaded if you want to try our app!
    - After downloading Flutter, run the command "flutter doctor" in the terminal to make sure you have everything needed for flutter to run.

- After cloning this project and navigating to the folder that it is located in, cd into the cs1530 folder. Here run "flutter pub get" to make sure all dependencies are downloaded so that the app can run. Then run "flutter run" to try out the application.

- You will initially be taken to the review page. You can hit the "Add Review" button to the top of the page to search for a song/album that you would like to review.
    - Note that we do not have a complete song/album database set up in our system, so you may not be able to search for every song or album that you would like. 
- Upon searching for an item that you would like to review (e.g. type "swe" into the search bar and Ariana Grande's Sweetener will populate), click on the music item and you will be redirected to another page.
- Here you can rate/review the song. You can change the number of stars that you would give the song, and you can type your review into the text box. You can rate a song without giving it a review, and you can give a song 0 stars.

- You can navigate to the friends page, where you can scroll through various user profiles and add/remove them as a friend. If you then navigate to the chat page, you can chat with the friends you have added.
